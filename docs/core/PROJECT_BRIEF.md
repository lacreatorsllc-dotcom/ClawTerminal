# Project Brief

## Product
SLUGS iOS — a mobile command center for AI agents.

## Problem
People running AI agents have no good mobile interface. They're stuck using terminals, generic chat tools, or nothing. They can't easily talk to agents from their phone, monitor what agents are doing, manage multiple agents, or upgrade agents with new skills.

## Solution
A premium iOS app that connects to existing agents via a simple setup command. Once connected, users can message agents, monitor activity, visualize their agent network, and assign skills from a curated marketplace.

## Target User
Technical and semi-technical builders who already run AI agents locally or in cloud/workspace environments.

## MVP Scope

### Must ship v1
1. Auth / onboarding
2. Agent connection flow (setup command / snippet)
3. Connected agents list
4. Agent detail screen
5. Chat / messaging with individual agents
6. Visual node-based agent view
7. Basic agent activity / status visibility
8. Marketplace screen with curated skills
9. Skill assignment to agent
10. Skill assignment confirmation

### Explicitly out of scope v1
- Open skill publishing
- Marketplace monetization
- Multi-agent automation builder
- Team collaboration
- Web version as primary
- Broad agent provider integrations beyond MVP connector

## User Flow
Download → Sign up → Connect agent (run setup command) → Agent appears connected → Open agent → Send message → View status/nodes → Visit Marketplace → Select skill → Assign to agent → Confirmation
