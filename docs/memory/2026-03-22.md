# Frontend Plan

## Component Breakdown

**Auth Screen**
- Email input + CTA
- Magic link handler

**Onboarding**
- CLI command display (mono font, copy button)
- Progress indicator

**Agents List**
- Agent cards (status dot, last message preview)
- Bottom tab nav
- Empty state + Connect CTA
- Connect Agent modal trigger

**Connect Agent Modal**
- Step indicator
- Command display + copy
- Status polling (pulsing indicator)
- Success state with agent preview

**Agent Detail (Chat/Status/Activity tabs)**
- Tab switcher (swipeable)
- Chat bubble list (inbound/outbound styling)
- Chat input + send button
- Status card (uptime, version, environment)
- Activity feed (event list with timestamps)

**Skills Browser**
- Skill card grid (category badge, description, assign CTA)
- Category filter chips

**Skill Detail**
- Skill header (name, category, version)
- Capability list
- Agent picker dropdown
- Assign CTA + confirmation toast

**Settings**
- Account section (email, sign-out)
- Notifications toggle
- API key display + copy

## Zustand Stores Needed

- **authStore** | user session, auth token, email
- **agentsStore** | connected agents list, active agent, connection status, last_seen
- **chatStore** | message history per agent, optimistic updates queue
- **skillsStore** | available skills catalog, assigned skills, filters
- **uiStore** | bottom tab state, sheet visibility, toasts

## Reusable Primitives to Build First

- Button (primary, secondary, ghost, destructive variants)
- Card (with surface bg, border, padding)
- Text (title-xl, title-lg, body, body-sm, label, mono styles)
- Status indicator (dot + label, color-coded)
- Chat bubble (inbound/outbound, mono code support)
- Input field (text, password, email)
- Bottom sheet modal (slides from bottom, dismissible)

## Mocks Acceptable in v1

- Agent status polling (hardcoded 30s intervals during connect flow)
- Message persistence (in-memory, wipes on app close)
- Skill catalog (5-10 JSON fixtures, no pagination)
- Activity feed (timestamp-only, no real event filtering)

## Risks

- Chat input loses focus on soft keyboard dismiss — test early, may need Reanimated keyboardHeight listener
- Supabase Realtime latency if no network — fallback to optimistic chat UI required
- Agent card list re-render thrashing on frequent status updates — memoize with Zustand selectors
